# AI Knowledge Platform

## 🎯 The Purpose
The goal of this project is to build a relatively small internal AI knowledge platform from scratch. 

From a product perspective, it allows users to upload documents and ask an AI questions about those documents (RAG). 
From an engineering perspective, it serves as a vehicle to learn end-to-end production engineering: moving from a simple local MVP to a distributed, scalable, and observable production system.

## 🧠 Engineering Philosophy
**Build → Deploy → Observe → Break → Understand → Improve → Scale**
- Start with the simplest architecture that works.
- Deploy early (Day 7).
- Introduce complexity (Queues, Redis, CI/CD, Kubernetes) only when there is a concrete reason to do so.

## 🚀 Phase 1 Features (MVP)
- User Authentication (Register/Login)
- Document Upload and Listing
- Basic Chat Interface
